Developer Guide

AI Pair Programming Workflow

A simple 4-step execution flow for collaborating between Antigravity (IDE) and ChatGPT.

💡

Important Developer Rule: Read Before Executing AI Outputs

Do not rely 100% blindly on ChatGPT or AI IDEs. ChatGPT can sometimes hallucinate, overcomplicate simple tasks, or loop unnecessarily. Always read the top summary and bottom explanation text of ChatGPT's response. Engage your human brain to verify that the proposed approach makes logical sense before pasting prompts back into your IDE!

1
Initialize Session in Antigravity (IDE)

Start a fresh chat in your AI IDE (Antigravity). Copy the prompt below to index the workspace documents and set your module scope.

  • Open Antigravity IDE and start a NEW chat window.
  • Click Copy Prompt below, paste it into Antigravity, and hit run.
  • Antigravity will ask who you are (Farooq, Nikitha, Divya, Ankit, Mithun) and freeze your module scope.
Master AI Starter Prompt 
You are an expert pair-programming assistant for the NextGen Digital Banking Platform. We are building a Spring Boot + PostgreSQL + React modular monolith (with a standalone Python AI service).

Before writing any code or suggesting implementation steps, follow these setup steps:

---

### STEP 1: Context Indexing & Document Analysis

Read and analyze the following files in the project workspace:
1. `TEAM-MESSAGE.md` — Project Kickoff Brief & Team Assignments
2. `PROJECT-STATUS.md` — Current phase and component status
3. All 12 design files inside `/docs/`:
   - `01-domain-model.md`
   - `02-business-events.md`
   - `03-service-boundaries.md`
   - `04-database-erd.md`
   - `05-sequence-diagrams.md`
   - `06-state-machines.md`
   - `07-business-rules.md`
   - `08-api-contracts.md`
   - `09-rbac-matrix.md`
   - `10-architecture-decisions.md`
   - `11-nfr-and-failure-handling.md`
   - `12-testing-and-observability.md`
4. Inspect `backend/src/main/java/com/nextgen/bank/common/` to understand existing shared Enums, Value Objects (`Money`, `Phone`, `Email`, `PAN`, `Aadhaar`, etc.), DTOs (`ApiError`), and Outbox event mechanisms.

---

### STEP 2: Developer Identification & Scope Freeze

Ask me:
"Which team member are you?
1. Farooq (Auth, Customer, Loan)
2. Nikitha (Account, Card)
3. Divya (Transaction Core, UPI)
4. Ankit (Beneficiaries, Notification, Audit)
5. Mithun (Lead — Common, AI Integration, Full Wiring)"

Wait for my response. Once I answer:
- Acknowledge my assigned backend package (`com.nextgen.bank.`) and frontend module folder (`frontend/src/modules/`).
- Summarize my primary responsibilities, my upstream/downstream dependencies, and the exact files in `/docs/` relevant to me.
- Remind me of the 5 Golden Rules:
  1. Stay strictly inside my package (`com.nextgen.bank.`). Never import internal classes from another module. Use public `Service` interfaces only.
  2. Use shared enums and VOs from `com.nextgen.bank.common`. Do not create duplicate enums or VOs.
  3. API endpoints must match `08-api-contracts.md` exactly (path, DTO request/response keys, status codes).
  4. Every state change must conform to `06-state-machines.md`.
  5. Every domain event listed in `02-business-events.md` for my module MUST be published to `ApplicationEventPublisher`.

Ready! Please ask me who I am to begin.

3
Get Strategy & Execution Prompt from ChatGPT

Since ChatGPT does not have complete codebase access, instruct ChatGPT NOT to guess exact technicalities or force code details. Tell ChatGPT to generate a strategy prompt that lets Antigravity inspect the codebase directly.

Prompt to send to ChatGPT 
Since you do not have direct access to our codebase, please do NOT try to decide specific code implementations, endpoint details, or technicalities. 

Instead, provide a clear high-level strategy and give me an IDE-executable prompt that I can paste into Antigravity (or any IDE AI agent). The prompt should instruct Antigravity to directly inspect the codebase, verify existing files, and make the specific technical decisions itself while building the feature step-by-step.
4
The ChatGPT <--> Antigravity Iteration Loop

Execute ChatGPT's generated prompt in Antigravity. Then copy Antigravity's output back to ChatGPT to verify quality. Repeat this feedback loop to push Antigravity to its best output!

  • Paste ChatGPT's generated prompt into Antigravity IDE and run it.
  • Copy the output/code changes Antigravity generated.
  • Paste it back into ChatGPT using the verification template below.
  • Read ChatGPT's top & bottom summaries to check if the logic makes sense before running the next prompt in Antigravity!
